\ Консольный калькулятор 



Простой и надежный калькулятор на Python для простых математических операций.



\ Возможности

\- Сложение, вычитание, умножение, деление.

\- Вычисление процентов.

\- Защита от деления на ноль и некорректного ввода.

\- Красивое консольное меню.



\ Как запустить

1\. Установите Python 3.

2\. Скачайте проект.

3\. Запустите:

```bash

python main.py
